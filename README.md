# react-big-schedule website

Docs, live demos and the theme playground for [react-big-schedule](https://github.com/ansulagrawal/react-big-schedule). Vite, React and Tailwind CSS; pages are pre-rendered at build time.

```bash
bun install
bun run dev      # http://localhost:5173
bun run build    # client build + pre-render (dist/) with sitemap, llms.txt and the agent skill
```

- Deploy: pushes to `master` deploy on Vercel (`vercel.json`); production URL https://react-big-schedule.vercel.app.
- Demos live in `src/demos/registry.tsx`; the docs' API reference is `content/reference.md`.
- Site URL for canonical links and the sitemap: `src/seo.ts`.
- AI files: `public/llms.txt`, `public/skills/react-big-schedule/SKILL.md`; `llms-full.txt` is generated by `scripts/llms.mjs`.
